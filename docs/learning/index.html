Cortex-M, TrustZone and TF-M on Renesas RA

From an empty mental model to being able to read a fault dump from an isolation-level-3 TF-M build on an RA6M5, explain it, and decide what to change. Every claim from Part 1 onward is tied to a file, a line, or a measurement in this repository.

Who this is for, and how to read it

  • You write C and read datasheets, are integrating or extending TF-M on RA6M5 or RA8M2, and have not yet worked with privilege levels, an MPU, TrustZone or a secure partition manager.
  • Read in order; Part 0 can be skimmed. For one task: a fault dump, Part 1 §1.8–1.9; a peripheral in a partition, Part 3 §3.9; choosing an isolation level, Part 3 §3.3–3.5; a new part, Part 4.
  • Answers to each page's questions are folded under them.

Four kinds of claim, and why the tags matter

Every substantive claim carries one of four tags, because confusing them is the commonest route to a wrong conclusion:

TagMeansExampleCan it change?
Armv8-MThe Arm architecture requires it. True on every Cortex-M33/M85. Unprivileged code cannot write the NVIC.No.
TF-MTrusted Firmware-M chose it. True on every TF-M platform, until TF-M changes. Above isolation 1, an Application-RoT FLIH handler runs in Thread mode.Upstream, by patch.
RARenesas silicon or the FSP does it. True on RA parts. An interrupt's security state lives in both NVIC->ITNS and ICUSARG.Per device / FSP release.
This portThis repository chose it. The port marks interrupts Secure only through the secure e2 project, never with NVIC_ClearTargetState().Here.

Citation conventions

  • D113 links to an entry in DECISIONS.md, the rationale log. Current behaviour is described in DESIGN.md and CONFIGURATION.md.
  • Links to repository documents open renderings under ref/, produced by python scripts/build_doc_html.py (see README.md).
  • tfm_hal_isolation_v8m.c:410 is in trusted-firmware-m, under platform/ext/common/ unless a fuller path is given. Port files are cited as ra6m5/tfm_timer0_irq.c:86, FSP files from the generated e2 project. Line numbers can drift with port commits.
