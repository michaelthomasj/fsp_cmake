Glossary and sources

Terms

AAPCS
Procedure Call Standard for the Arm Architecture: argument registers, callee-saved registers, stack alignment. 0.3
AIRCR
Application Interrupt and Reset Control Register, 0xE000ED0C. Holds PRIS and BFHFNMINS. 2.5
ARoT
Application Root of Trust. Partitions with "type": "APPLICATION-ROT"; unprivileged from isolation 2. 3.1
Azone
The e2 .secure_azone file holding peripheral-to-security-zone assignments. 2.7
BFAR, BFSR
BusFault Address Register (0xE000ED38) and status byte CFSR[15:8]. 1.8
BL2
TF-M's second-stage bootloader; MCUboot here.
CFSAMONA/B, SSAMONA/B, DFSAMON
RA6-family PSCU boundary registers that drive the IDAU; set by RDPM. RA8M2 has only a read-only CFSAMONA. 2.2
BXNS / BLXNS
Branch (with link) to Non-secure state; how Secure code returns to or calls Non-secure code. 2.3
CFSR
Configurable Fault Status Register, 0xE000ED28 = MMFSR | BFSR | UFSR. 1.8
CMSIS
Arm's Common Microcontroller Software Interface Standard: the core headers (core_cm33.h), register structs and intrinsics such as NVIC_SetPriority. 0.8
CMSE
Cortex-M Security Extensions: the compiler support (-mcmse, cmse_nonsecure_entry, cmse_check_address_range). 2.3
CONTROL
Special register: nPRIV, SPSEL, FPCA, SFPA. 1.2
CPSCU / PSCU
RA's (CPU) Peripheral Security Control Units: ICUSARG, SRAMSAR; PSARx, PPARx, boundary registers. 2.7
DCRS
EXC_RETURN bit 5: default callee-register stacking. 0 means R4–R11 were stacked by hardware. 1.6
e2 studio / RASC
Renesas IDE and its configurator (Smart Configurator), which generate the FSP projects this port consumes.
EXC_RETURN
The value in LR on exception entry; encodes how to return. 1.6
FF-M, PSA-FF-M
PSA Firmware Framework for M-profile: the specification TF-M implements. 3.1
FLIH / SLIH
First- / Second-Level Interrupt Handling. 3.6
FSP
Renesas Flexible Software Package: BSP and drivers for RA.
HFSR
HardFault Status Register, 0xE000ED2C; FORCED = escalation. 1.8
ICU, IELSR
RA Interrupt Controller Unit and its Event Link Setting Registers, which route peripheral events to NVIC lines. 0.8
ICUSARG
RA ICU security attribution register; must agree with NVIC_ITNS. 2.6
IDAU
Implementation-Defined Attribution Unit. 2.2
IPC / SFN backend
TF-M's threaded vs function-call SPM implementations. 3.5
ITNS
NVIC Interrupt Target Non-secure registers, 0xE000E380. 2.5
ITS / PS
Internal Trusted Storage / Protected Storage partitions.
INVEP
SFSR bit 0: Non-secure code branched into Secure memory somewhere other than an SG in NSC memory. 2.3
LPMSAR
RA low-power-mode controller security attribution register, written by FSP at boot. 2.7
MAIR
MPU Memory Attribute Indirection Registers. 1.4
MMFAR, MMFSR
MemManage Fault Address Register (0xE000ED34) and status byte CFSR[7:0]. 1.8
MM-IOVEC
FF-M option letting a service map client memory directly; isolation 1 only, OFF on this port. 3.2
MMIO
Memory-mapped I/O: a peripheral's register block. A partition's mmio_region grants it one. 3.1
MPC / PPC
Memory / Peripheral Protection Controller, found on Arm reference subsystems; RA has neither. 2.7
MPU
Memory Protection Unit (PMSAv8). Banked per security state. 1.4
MSAR
RA8 MRAM security attribution register. 2.7
MRCPFB
RA8M2 MRAM controller register at 0x4013C000 whose Non-secure attribution caused D092's BusFault. 2.7
MSP / PSP, MSPLIM / PSPLIM
Main / Process stack pointers and their limits. 1.3
NSC
Non-secure Callable: memory where an SG may be the target of a Non-secure branch. 2.3
NSACR
Non-secure Access Control Register: which coprocessors (e.g. the FPU) Non-secure code may use. Secure-only. 2.4
NSPE / SPE
Non-secure / Secure Processing Environment. 3.1
NVIC
Nested Vectored Interrupt Controller. 0.8
OFS
RA option-setting memory: at 0x0100A100 on RA6M5, from 0x02C9F040 on RA8M2 (with a different set of words). 4.6
PendSV
Pendable service exception, 14; TF-M's context switch. 1.7
PPB
Private Peripheral Bus, 0xE0000000–0xE00FFFFF; privileged-only. 0.10
PRIMASK / BASEPRI / FAULTMASK
Exception masks: all configurable exceptions; those at or below a priority; everything but NMI. Banked per security state; with AIRCR.BFHFNMINS = 0 the Non-secure copies boost priority only to 0 (0x80 with AIRCR.PRIS), so they never mask Secure exceptions (2.5). 0.6
PRIVDEFENA
MPU_CTRL bit 2: privileged background map. 1.4
PRIS
AIRCR bit: Secure exceptions prioritised over Non-secure. 2.5
PSA RoT
PSA Root of Trust: SPM plus core security services; privileged at every isolation level. 3.1
PSAR / PPAR
RA Peripheral Security / Privilege Attribution Registers. 2.7
PXN
Privileged Execute Never; MPU attribute in Armv8.1-M only. 3.8
RBAR / RLAR / RNR
MPU region base, limit and number registers. 1.4
RDPM
Renesas Device Partition Manager: programs the TrustZone boundaries; erases the part. 2.8
SAU
Security Attribution Unit. 2.2
SCB / SCS
System Control Block / System Control Space. 0.10
SFSR / SFAR
SecureFault status and address registers, 0xE000EDE4/E8. 1.8
SG
Secure Gateway instruction. 2.3
SID
Service ID. 3.1
SPM
Secure Partition Manager. 3.5
SRAMSABARn
RA8M2 CPSCU registers splitting SRAM into Secure and Non-secure; written by FSP at boot, whatever RDPM is given. 2.2
SVC
Supervisor Call instruction and exception 11. 1.7
tfm_sprt
Secure Partition Runtime library, linked into the unprivileged code region; its .bss is not. 3.8
TT
Test Target instruction: reports MPU and SAU/IDAU attributes of an address. 2.1
VTOR
Vector Table Offset Register, 0xE000ED08. 0.5
